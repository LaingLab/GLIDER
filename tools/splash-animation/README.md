# Splash animation

The launch splash (`src/glider/assets/splash.gif`), made with [Remotion](https://www.remotion.dev/).

- `npx remotion studio` — preview and tweak in the browser.
- `./build.sh` — cut the art from `packaging/icons/glider_source_original.png`, render, and write the GIF.

The composition is 1200×600; the app shows it at 600×300 so it is crisp on HiDPI screens.
